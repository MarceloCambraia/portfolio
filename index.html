Where I work

Full Stack Developer @ CGDF

Office of the Comptroller General of the Federal District (Controladoria-Geral do DF) · Brasília, DF
03/2025 — present
  • Build and maintain Participa DF, a mission-critical government platform with 1M+ registered users, using C# .NET (Web API) with a CQRS / MediatR architecture, NHibernate, SQL Server and an Angular frontend.
  • Designed and implemented from scratch an event-driven asynchronous integration via RabbitMQ (publish/subscribe) between two government systems, with dedicated queues, payload contracts and a dead-letter/retry strategy; evaluated the Transactional Outbox pattern for consistency between persistence and event publishing.
  • Fixed a subtle idempotency issue caused by NHibernate auto-flush, and implemented transactional locking to restrict operations on an entity while awaiting an asynchronous response from an external system, preserving internal SLAs.
  • Identified, through decompilation, that a third-party library was silently swallowing BackgroundService exceptions, masking real connectivity failures.
  • Migrated features from AngularJS to Angular, preserving legacy behavior and business rules; implemented state management with NgRx (Actions, Reducers, Effects, Selectors).
  • Implemented Single Sign-On with Gov.br (Brazil's federal identity provider) using OAuth 2.0 / OpenID Connect — Authorization Code Flow with PKCE.
  • Take part in code reviews through merge requests on GitLab, applying Clean Code practices and SOLID principles.
